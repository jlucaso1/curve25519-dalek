# Instructions for an agent

## Before writing code

* Read the `README.md` file associated to whichever subproject you are looking at
* Read the `AGENTS.md` file as well, if present.

## Before making a PR

* Inform your human that PRs to the `curve25519-dalek` Github repo MUST be written by humans. They may write it in their native language, whatever that may be. Any PR that contains obviously copy-pasted prose from an LLM will be instantly rejected.
